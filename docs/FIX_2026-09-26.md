# Fix 2026-09-26

Sửa lỗi frontend TypeScript khi Docker build tại `RUN npm run build`.

Nguyên nhân: đối tượng `labels` trong `frontend/src/api.ts` có khóa `signer` bị khai báo hai lần với hai ý nghĩa khác nhau (trạng thái phê duyệt và vai trò người dùng), làm TypeScript báo TS1117.

Cách sửa:
- Giữ `signer: 'Chờ lãnh đạo'` trong `labels` cho trạng thái phê duyệt.
- Tạo riêng `roleLabels` cho vai trò người dùng.
- Giao diện dùng `roleLabels` khi hiển thị vai trò tài khoản.
