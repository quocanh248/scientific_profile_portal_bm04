# Fix Nginx 500 at root URL (2026-09-26)

Symptom: containers are Running/Healthy but opening `http://127.0.0.1:8080` returns `500 Internal Server Error` from nginx.

Cause: the custom `nginx/default.conf` replaced the image's default server block but did not declare the SPA document root. `try_files` therefore could not reliably resolve `/index.html` and could enter an internal redirect cycle.

Fix added to the server block:

```nginx
root /usr/share/nginx/html;
index index.html;
```

After editing, rebuild only the web image:

```powershell
docker compose up -d --build web
```

Then verify:

```powershell
docker compose ps
docker compose logs --tail=50 web
```
